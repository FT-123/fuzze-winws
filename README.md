# Zapret Fuzzer & Strategy Tuner

GUI-подборщик стратегий обхода DPI для [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube).

Приложение берёт выбранный `general*.bat`, подставляет параметры `winws.exe`, запускает его,
проверяет доступность выбранных доменов по HTTPS и перебирает мутации стратегии, пока не найдёт
рабочую. Найденные параметры записываются обратно в `.bat` (старая версия сохраняется в `.bak`).

## Что чинит этот репозиторий

Ранее проект не запускался «из коробки» и мог испортить стратегию:

* отсутствовал `service.bat`, без которого любой `general*.bat` падает на `call service.bat ...`;
* правка `.bat` регулярками ломала флаг `--dpi-desync-any-protocol=1` (превращался в `--dpi-desync=... =1`);
* TCP-параметры применялись к UDP-секциям, а разные профили `--new` затирались одним;
* импорт/экспорт пресетов и окно истории вызывали несовпадающие функции и падали с `TypeError`;
* история не сохранялась, метрики в GUI не обновлялись, обращения к Tk из фоновых потоков были небезопасны.

Теперь правка `.bat` учитывает секции `--new`: TCP-десинк меняется только в TCP-профилях,
UDP-профили сохраняют свою стратегию, а `--dpi-desync-any-protocol` обрабатывается как отдельный флаг.

## Требования

* Windows 10/11;
* Python 3.10+;
* права администратора — `winws.exe`/WinDivert не работают без них;
* файлы движка zapret рядом с приложением:
  * `bin/` (`winws.exe`, `WinDivert.dll`, `WinDivert64.sys`, `cygwin1.dll`, `.bin`-файлы фейков);
  * `lists/`;
  * `service.bat`;
  * `utils/`.

`bin/`, `lists/`, `service.bat` и `base bats/` — сторонние файлы из
[Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) (GPLv2,
права принадлежат авторам zapret и сборки). Они не входят в Python-пакет приложения и в `.gitignore`.

## Установка

### Вариант 1 — установщик (рекомендуется)

1. Запустите `ZapretStrategyTuner-Setup-<версия>.exe`.
2. Установщик не требует прав администратора: он ставит всё в
   `%LOCALAPPDATA%\Zapret Strategy Tuner` для текущего пользователя.
3. На рабочем столе и в меню «Пуск» появятся ярлыки.
4. При запуске ярлыка Windows запросит UAC — это нужно для winws/WinDivert.

Установщик **не содержит** `list-general-user.txt` и `list-exclude-user.txt`:
они создаются при первом запуске и не удаляются при обновлении/удалении.

Сборка установщика:

```bat
pip install -r requirements-build.txt
python scripts/build_installer.py
```

Нужен Inno Setup 6 (`ISCC.exe`). Результат — `dist\installer\ZapretStrategyTuner-Setup-<версия>.exe`.

### Вариант 2 — поверх готового релиза zapret

1. Скачайте и распакуйте релиз `zapret-discord-youtube`.
2. Скопируйте в эту папку файлы приложения: `main.py`, `gui.py`, `presets.py`, `updater.py`,
   `fuzzer_engine.py`, `config.py`, `validators.py`, папку `ui/` (и `tests/`, если нужны тесты).
3. `pip install -r requirements.txt`
4. Запустите `python main.py` **от имени администратора**.

Рядом уже будут `bin/`, `lists/`, `service.bat`, `utils/` и `general*.bat`.

### Вариант 3 — клонировать репозиторий

```bat
git clone https://github.com/FT-123/fuzze-winws.git
cd fuzze-winws
pip install -r requirements.txt
```

Затем скопируйте из архива zapret в папку проекта папки `bin/`, `lists/`, `utils/` и файл
`service.bat`. При первом запуске приложение само скопирует `general (ALT11).bat` из `base bats/`,
если корневой стратегии ещё нет.

Если чего-то не хватает, приложение покажет список отсутствующих файлов, а не молча запустит
сломанный батник.

## Права администратора

winws/winws2 и WinDivert требуют прав администратора. При запуске без них приложение
покажет запрос на перезапуск с повышением прав; собранный `fuzzer.exe` дополнительно
имеет манифест `requireAdministrator`, поэтому ярлык сразу вызывает UAC.

## Личные списки доменов

Пользовательские списки не входят в установщик и не перезаписываются обновлением:

* `list-general-user.txt` — домены, которые нужно обходить;
* `list-exclude-user.txt` — домены, которые нельзя трогать (имеют приоритет).

Управлять ими можно из приложения: **«Целевые домены» → «Списки доменов»**.
Можно добавлять вручную, вставлять списком, импортировать TXT и редактировать как текст.
Изменения применяются после перезапуска стратегии.

В установленной версии всё приложение и его данные будут лежать рядом в
`%LOCALAPPDATA%\Zapret Strategy Tuner` — это позволяет обновлять программу без
прав на запись в Program Files и сохранять личные списки.

## Использование

По умолчанию интерфейс максимально простой:

1. Нажмите на сервисы, которые нужно разблокировать: `YouTube`, `Discord`,
   `Telegram`, `Steam`, `Gemini` (или найдите приложение по имени).
2. Выберите режим: `Быстрый`, `Стандартный` или `Глубокий`.
3. При необходимости откройте **«Списки доменов»** и добавьте домены в обход или исключения.
4. Нажмите **«Настроить и запустить»**.

Дальше приложение делает всё само:

* проверяет DNS (системный и DoH) и предупреждает о подмене;
* определяет, что именно блокируется: HTTP, TLS 1.2, TLS 1.3, QUIC, IP;
* если сервисы уже доступны — не трогает конфиг;
* ищет стратегию по семействам: split → fake + TTL → fooling → faked →
  hostfake → комбинации → wssize/syndata → QUIC;
* сначала проверяет кандидата на одном canary-домене, затем на всех;
* делает повторы, чтобы не принять случайный успех за рабочий;
* минимизирует найденную стратегию (убирает лишние флаги);
* записывает результат в `auto-config.bat`, запускает winws и проверяет его.

Следующий запуск приложения автоматически выберет `auto-config.bat`.

Кнопка **«Дополнительно»** в шапке открывает ручные настройки: выбор исходного
`.bat`, разовый тест, редактирование параметров, службу winws, восстановление
базовых батников. Обычному пользователю туда заходить не нужно.

История запусков (включая диагностику и найденную стратегию) — кнопка
«История» в расширенном режиме.

Порог успеха по умолчанию — 50% доступных доменов; галочка `100% пробив`
в расширенном режиме требует все домены.

### Режимы поиска

* **Быстрый** — 1 попытка, простые split/fake, ограничение по времени 5 минут.
* **Стандартный** — 2 попытки, fake/faked/hostfake/комбинации, 20 минут.
* **Глубокий** — 3 попытки, больше TTL/фоллингов/повторов, wssize/syndata/QUIC, до часа.

Поиск останавливается досрочно, как только стратегия прошла canary, все домены
и финальную проверку стабильности.

## Поддержка winws2 / Lua

Если выбранный `.bat` использует `winws2` и `--lua-desync`, приложение:

* разбирает профили, `--payload`-группы и инстансы Lua;
* меняет только инстансы, сохраняя `--lua-init`, блобы, фильтры и незнакомые параметры;
* сохраняет сервисные особенности вроде `tls_mod=sni=www.google.com` и кастомных блобов;
* ищет стратегии для TLS, HTTP и QUIC отдельно;
* пишет исправленный батник в `auto-config.bat`.

Для winws2 нужны `bin/winws2.exe`, `lua/zapret-lib.lua`,
`lua/zapret-antidpi.lua` (или те же файлы в `bin/lua/`).

### Как переключиться на zapret2

Отдельного глобального тумблера нет: движок определяется **по выбранному `.bat`**.

1. Скопируйте в папку приложения `bin/winws2.exe`, `WinDivert.dll`, `WinDivert64.sys`,
   `cygwin1.dll` и папку `lua/` с `zapret-lib.lua` и `zapret-antidpi.lua`.
2. Возьмите `.bat` для winws2 (с `--lua-init`, `--payload` и `--lua-desync`).
3. Откройте **«Дополнительно»** → «Файл стратегии» → «Обзор» и выберите этот батник.
4. В заголовке карточки появится `движок: winws2 (Lua)`, а в журнале — `Текущий движок: winws2`.
5. Нажмите «Настроить и запустить»: приложение будет править Lua-инстансы и писать
   `auto-config.bat` уже для winws2.

Если выбран winws1-батник, приложение работает через `winws.exe`. Автоматической
конвертации winws1-батника в Lua-стратегию нет: это разные модели, и конвертация
может сломать смысл стратегии. `auto-config.bat` всегда сохраняет движок исходного батника.

В проекте уже подготовлен `general (ZAPRET2).bat` с профилями TLS/HTTP/QUIC и
Discord/STUN; он выбран в `settings.json`. После копирования файлов zapret2
приложение стартует с `движок: winws2 (Lua)`.

## Интерфейс

Светлая/тёмная тема в духе Gemini: карточки с тонкими рамками, скруглённые
кнопки, синий акцент и градиентная линия в футере. В простом режиме на экране
только выбор сервисов, метрики, журнал и одна главная кнопка.

В шапке есть переключатели **светлой/тёмной темы** и **«Дополнительно»**.
Выбор темы и список последних сервисов сохраняются в `settings.json`.

Во время диагностики и поиска в карточке метрик показывается бегущая полоса,
текущий этап и таймер; журнал печатает этапы и каждый проверенный домен, поэтому
видно, что программа работает, а не зависла.

## Что приложение меняет в системе

* завершает процессы `winws.exe`/`winws2.exe` и останавливает службу `WinDivert`
  перед диагностикой и тестами;
* дописывает выбранные домены в `lists/list-general-user.txt` (базовые списки не трогает);
* создаёт временные `_fuzzer_temp.bat` / `_fuzzer_run.bat` и удаляет их после теста;
* при успехе пишет `auto-config.bat` и запускает его;
* исходный выбранный `.bat` не изменяется (ручное «В .bat» в расширенном режиме — изменяет,
  с бэкапом `.bak`).

Не запускайте настройку одновременно с другим экземпляром zapret: они будут
убивать `winws.exe` друг друга.

## Обновление

В установленной версии приложение проверяет последний релиз GitHub при запуске.
Если версия новее, внизу появляется кнопка **«Обновить до vX»**.

По нажатию:

1. скачивается `ZapretStrategyTuner-Setup-<версия>.exe` и `SHA256SUMS.txt`;
2. SHA256 установщика проверяется;
3. приложение останавливает winws и закрывается;
4. установщик ставится тихо в `%LOCALAPPDATA%`;
5. приложение запускается заново.

Личные списки, `settings.json` и `history.json` не затрагиваются.
Автообновление доступно только для установленной версии; при запуске из исходников
кнопка предложит скачать установщик вручную.

Установщик не подписан, поэтому SmartScreen может показать предупреждение.

## CI и релизы

- `.github/workflows/ci.yml` — тесты и компиляция на push/PR.
- `.github/workflows/release.yml` — по тегу `v*` или вручную:
  - подтягивает движок из Flowseal `1.9.6` и zapret2 `v1.0.4`;
  - собирает `fuzzer.exe` и установщик;
  - создаёт `SHA256SUMS.txt`;
  - публикует GitHub Release с установщиком.

Релиз: создать тег `v1.0.1` и запушить. Workflow сам подставит версию в приложение и установщик.

## Разработка

Планируемая архитектура умного подбора стратегий (диагностика → семейства →
canary-поиск → минимизация → портфель) описана в
[`docs/strategy-search.md`](docs/strategy-search.md).

```bat
pip install -r requirements-dev.txt
python -m pytest tests -q
```

Сборка одного exe (PyInstaller с UAC-манифестом):

```bat
python scripts/build_installer.py --skip-inno
```

Полный установщик собирается через `python scripts/build_installer.py` (нужен Inno Setup 6).
Собранный `fuzzer.exe` кладётся в папку с `bin/`, `lists/`, `service.bat`; `config.py`
определяет пути относительно exe, а не текущей директории.


## Известные ограничения

* Проверка доступности — HTTPS-хендшейк с валидацией сертификата. Если провайдер отдаёт
  подменённую страницу с валидным сертификатом, проверка может дать ложный успех.
* `googlevideo` проверяется через `/generate_204`; поведение CDN может отличаться по регионам.
* Автообновление работает только для собранного `fuzzer.exe`; запуск из исходников файлы не подменяет.
* `pystray`/`Pillow` опциональны: без них используется простое окно-оверлей вместо трея.
