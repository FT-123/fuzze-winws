# fuzze-winws (ZAPRET Fuzzer & Strategy Tuner)

Графическая утилита на Python (Tkinter) для автоматического подбора и оптимизации параметров обхода DPI в `winws.exe` (компонент проекта **Zapret** для Windows). 

Программа перебирает комбинации настроек стратегий (TCP split, sequence overlap, TTL, UDP repeats/cutoff) и тестирует их эффективность на выбранных целевых сервисах, помогая найти рабочий вариант обхода под вашего провайдера.

---

## 🌟 Основные возможности

- **Автоматический фаззинг (Fuzzing / Tuning)**: Автоматический перебор и тестирование параметров `winws` (значения `split-pos`, `seqovl`, `ttl`, `repeats`, `cutoff`) с проверкой доступности узлов через `curl`.
- **Встроенные пресеты целевых сервисов**:
  - **YouTube**: Основные домены и CDN-серверы (`googlevideo`).
  - **Discord**: Голосовые каналы, текстовый чат, CDN и RTC.
  - **Telegram**: Мессенджер, медиасеть и веб-версия.
  - **Steam**: Магазин, сообщество и инвентарь.
  - **Twitch**: Прямые трансляции и чат.
  - **ChatGPT / OpenAI**: Веб-интерфейс и API.
  - **Spotify**: Музыкальный сервис и подкасты.
  - **Другие**: Instagram / Meta, Twitter / X, Notion, Rainbow Six Siege и др.
- **Синхронизация списков доменов**: Автоматическое добавление тестируемых доменов в текстовые списки `winws` (`list-general.txt`, `list-discord.txt`, `list-youtube.txt` и др.).
- **Управление сетевыми службами**: Очистка кэша DNS Windows (`ipconfig /flushdns`), автоматическое завершение процессов `winws.exe` и перезапуск драйвера `WinDivert`.
- **Графический интерфейс и системный трей**: Удобное окно на базе Tkinter, просмотр истории прогонов, тонкая настройка параметров и сворачивание в системный трей.
- **Модуль автообновления**: Проверка и загрузка свежих версий программы.

## ⚙️ Принцип работы фаззинга

1. Приложение формирует комбинации параметров из заданных диапазонов:
   - **POS Range**: `(1, 2, 3, 4, 5, 6)`
   - **TTL Range**: `(3, 4, 5, 7, 8)`
   - **SEQ Range**: `(100, 300, 500, 681, 800, 1000, 1200)`
   - **Cutoff Range**: `("n2", "n3", "d2", "d3", "d4")`
   - **Repeats Range**: `(4, 6, 10, 12, 15)`
2. Подставляются параметры в выбранный командный файл `.bat`.
3. Запускается экземпляр `winws.exe`.
4. Выполняется серия запросов через `curl` к целевым доменам.
5. Фиксируются время отклика и статус доступности ресурса. Лучшие конфигурации сохраняются в историю.

## 🚀 Установка и запуск

### Требования
- **ОС**: Windows 10/11 (требуются права администратора для работы `WinDivert` и `winws`).
- **Python**: 3.10 или новее.
- Установленный и настроенный пакет `Zapret` с исполняемым файлом `winws.exe`.

### Запуск из исходного кода

1. Клонируйте репозиторий:
   ```bash
   git clone [https://github.com/FT-123/fuzze-winws.git](https://github.com/FT-123/fuzze-winws.git)
   cd fuzze-winws

```

2. Установите необходимые зависимости:
```bash
pip install -r requirements.txt

```


*(При отсутствии `requirements.txt` убедитесь в наличии `pystray`, `Pillow` и стандартных библиотек Python)*.
3. Запустите приложение от имени администратора:
```bash
python main.py

```

## 📖 Использование

1. Выберите нужный **пресет** (например, `YouTube` или `Discord`) или укажите свой список доменов.
2. Укажите базовый `.bat` файл из папки `base bats/`.
3. Нажмите кнопку запуска фаззинга.
4. Дождитесь завершения прогона или остановите его вручную после нахождения рабочей конфигурации.
5. Просмотрите найденные рабочие комбинации в окне **Истории** и примените оптимальный вариант.
